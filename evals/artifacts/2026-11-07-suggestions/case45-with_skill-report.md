# Concurrency repair evidence

Implemented:
- Preserved the supplied event classes, SearchState API and SearchRepository boundary.
- Shared read generation across SearchChanged and SearchRefreshed. Latest intent owns query/loading/content/error; refresh keeps the selected query. Stale success/failure is ignored, and current failures retain useful content.
- Added a FIFO write tail independent of reads. IDs are reserved before queueing; duplicate pending/successful deliveries produce no extra repository calls. Failed IDs can be retried with the original payload. Payload conflicts produce saveError without an external call.
- Each failed write is handled inside its queued operation so the next distinct write executes. Read/save feedback preserves the other operation's fields.
- Every asynchronous handler awaits its work. Late completions check Emitter.isDone. Accepted queued writes continue after closing the Bloc, while no further states are emitted.
